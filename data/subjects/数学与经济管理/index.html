应用数学知识点结构化要点清单

知识点名称

应用数学 — 系统架构设计师考试中的数学计算类题型

核心定义/结论

1. 三机流水线调度（Johnson法）

  • 三道工序固定顺序时，构造虚拟合体数 G=工序1+工序2，H=工序2+工序3
  • G小的排前，H小的排后，每次从剩余中找全局最小值
  • 最终按甘特图逐步推算完工时间

2. 期望决策（概率决策树）

  • 期望收益 = Σ（各结果收益 × 对应概率）
  • 多阶段问题需注意条件概率：后阶段概率要乘以前阶段发生的概率
  • 最终比较各方案净期望收益（减去初期投资）

3. 盈亏平衡点

  • 盈亏平衡点 = 收入恰好等于全部支出时的销量
  • 方程：单价×X = 固定成本 + 可变成本率×单价×X + 税率×单价×X
  • 可变成本率 = 历史可变成本总额 ÷ 历史总收入

4. 计数问题（分位数数法）

  • 按数字位数分类（1位、2位、3位…）逐类计数
  • 每类内按"5出现在哪一位"分情况，用乘法原理计算
  • 注意首位不能为0的限制

5. 集合容斥原理

  • 三集合并集公式：|A∪B∪C| = |A|+|B|+|C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|
  • 都不属于任何集合的数量 = 总数 - |A∪B∪C|

典型题型与解题要领

题型解题要领
流水线调度先算G/H合体数 → 按Johnson法排序 → 画甘特图逐步推算
期望决策画时间轴拆阶段 → 每段=收益×年数×概率 → 条件概率要乘前提概率 → 减初期投资 → 比大小
盈亏平衡先算可变成本率 → 列方程"收入=固定+可变+税" → 解X
计数问题按位数分类 → 每类按5的位置分情况 → 乘法原理 → 各类相加
容斥原理套公式三加三减一加 → 用总数减并集

易错点与注意事项

流水线调度

  • 甘特图中每道工序的开始时间取"前一产品同工序完成"和"本产品上一工序完成"两者的较大值，漏掉这个等待逻辑会算错

期望决策

  • 后5年的期望要分两条路径分别乘以前提概率再相加，不能直接用后5年的条件概率单独算

盈亏平衡

  • 税率也是从收入中扣除的支出，必须纳入方程，漏掉税率是最常见错误
  • 可变成本率需要用历史数据推算，不能直接用绝对金额

计数问题

  • 三位数的百位不能填0（否则变成两位数），也不能填5（题目限制只有一个5），所以百位只有8种选择，不是9种

容斥原理

  • 公式方向不能反：是"加单项、减两两交、加三交"，顺序不能乱
  • 最后一步别忘了用总数减并集才是"都不会"的人数

推荐复习顺序

按性价比从高到低排列：

  1. 容斥原理（题号23）— 公式固定，计算简单，考试高频，5分钟能掌握，优先拿下
  2. 盈亏平衡点（题号35）— 方程思路清晰，记住"收入=固定+可变+税"即可，10分钟搞定
  3. 期望决策（题号45）— 步骤稍多但套路固定，理解条件概率的乘法是关键，15分钟理解思路
  4. 计数问题（题号3）— 逻辑清晰但细节多，重点记住"首位不能为0"的限制，了解思路即可
  5. 流水线调度（题号40）— 最复杂，手算甘特图耗时，考试中性价比最低，建议只记住G/H合体数和排序规则，遇到直接跳过或猜答案

> 前三个知识点值得花时间练习，后两个了解思路即可，把主要精力放在架构设计、质量属性、设计模式等核心高频考点上。

概率统计知识点结构化要点清单

知识点名称

几何概型与蒙特卡洛方法

核心定义/结论

几何概型

用面积（或长度、体积）之比来计算概率：

```

P(A) = 满足条件的区域面积 / 样本空间总面积

```

两个连续均匀分布的随机变量，其联合分布对应二维平面上的均匀分布，概率问题转化为几何面积问题。

蒙特卡洛方法（随机模拟）

在单位正方形内随机撒点，落在曲线 f(x) 下方的点占总点数的比例，近似等于该曲线的定积分值：

```

N/M ≈ ∫₀¹ f(x)dx

```

本质是"频率趋近于概率"的应用。

典型题型与解题要领

题型一：两变量时间差问题（41题）

解题步骤：

  1. 设两个随机变量为坐标轴，建立二维坐标系
  2. 确定样本空间（通常是矩形），计算总面积
  3. 将条件（如 |x-y| ≤ 4）转化为几何区域
  4. 用"总面积 - 不满足条件的面积"计算目标区域
  5. 概率 = 目标面积 / 总面积

关键技巧：|x-y| ≤ k 这类条件，不满足的部分是两个直角等腰三角形，边长为 (总范围 - k)。

题型二：随机模拟近似计算（58题）

核心判断：看到"大量随机点 + 满足某条件的比例"，直接联想定积分的几何意义，答案通常是"求积分"。

易错点与注意事项

  • 计算不满足条件的三角形边长时容易算错：边长 = 总范围 - 时间差阈值，本题是 10-4=6，不是 4 本身
  • 几何概型要求样本空间内均匀分布，非均匀分布不能直接用面积比
  • 蒙特卡洛题目中，N/M 近似的是积分值而非最大值/最小值/方程解，选项干扰项专门针对这点设计
  • 定积分的几何意义：是面积，不是函数值

推荐复习顺序

  1. 先理解几何概型的基本思想（面积比 = 概率）
  2. 练习建立二维坐标系、画出条件区域的方法
  3. 掌握 |x-y| ≤ k 类条件的标准解法
  4. 了解蒙特卡洛方法与定积分的关系
  5. 做真题验证，重点是建模过程而非计算

> 这两个知识点在系统架构师考试中属于低频超纲内容，理解思路、能识别题型即可，不需要深入推导。备考精力建议控制在 1-2 颗星。

动态规划 · 结构化知识点清单

（2013年11月系统架构真题 · 第44/46题）

一、知识点名称

动态规划（Dynamic Programming，DP） 及其近亲：线性规划 与 指派问题（匈牙利算法）

二、核心定义与结论

动态规划

  • 将大问题拆成有重叠子问题的阶段性决策序列
  • 每阶段记录当前最优解（状态），通过状态转移方程推进
  • 核心公式：dp[i][j] = max{ dp[i-1][j-k] + value_i(k) }，其中 k 为当前阶段分配量

线性规划（第44题实际考点）

  • 目标函数与约束条件均为线性关系
  • 本题核心：令上衣总数 = 裤子总数，最大化配套数量
  • 关键思路：比较效率比值，让"相对优势"决定分工

指派问题 · 匈牙利算法（第46题工时题考点）

  • 将 n 个人分配给 n 项任务，使总成本最小
  • 三步走：行归约 → 列归约 → 找独立零配对

三、典型题型与解题要领

题型1：资源分配型 DP（第46题投资题）

解题要领：

  1. 读表，建立各对象的效益函数
  2. 用第一个对象初始化 dp 表
  3. 逐个并入后续对象，枚举分配量 k，取最大值
  4. 最终 dp[n][总资源] 即为答案

```

给丙0，甲乙拿4：10.6 + 4.8 = 15.4

给丙1，甲乙拿3：10.0 + 6.4 = 16.4 ← 最大

给丙2，甲乙拿2：8.8 + 6.8 = 15.6

...

```

题型2：产能配套型线性规划（第44题）

解题要领：

  1. 计算各组"裤子/上衣"效率比，比值大的优先做裤子
  2. 固定两端（最大比值做裤子，最小比值做上衣）
  3. 设中间组的天数为变量，令上衣 = 裤子，解方程
  4. 在整数约束下取极值

题型3：指派问题（第46题工时题）

解题要领：

```

第一步：每行减去本行最小值（行归约）

第二步：每列减去本列最小值（列归约）

第三步：找独立零（每行每列各选一个0，互不冲突）

```

四、易错点与注意事项

DP 资源分配题

  • 易错：效益表读错，0投资时的基础效益容易漏掉
  • 注意：枚举 k 时范围是 0 ≤ k ≤ j，不能超过当前总资源
  • 注意：最终方案要回溯验证（如甲3+乙0+丙1 = 6.0+4.0+6.4 = 16.4）

线性规划配套题

  • 易错：误以为让所有人做效率最高的那项就最优，忽略了"配套约束"
  • 注意：最终要满足整数天数约束，x 和 y 必须是 0~15 的整数

匈牙利算法

  • 易错：列归约时忘记检查是否已有0（最小值为0时不需要减）
  • 注意：独立零的选取顺序影响过程，但最终结果唯一（完美匹配唯一时）
  • 注意：若归约后0的数量不足以完成配对，需要进行额外的覆盖线步骤（考试一般不考此情况）

五、推荐复习顺序

```

第1步 掌握 DP 资源分配（最常考，第46题投资题）

→ 理解状态转移，会填表，会枚举

第2步 掌握匈牙利算法三步走（第46题工时题）

→ 行减、列减、找独立零，流程固定，适合得分

第3步 了解线性规划配套思路（第44题）

→ 理解"效率比 + 等量约束"即可，不需要推导方程

第4步 综合练习

→ 遇到"分配资源求最优"先判断是哪类题型，再套对应流程

```

> 这三道题在真实考试中属于偏难/超纲范围，时间紧时优先保证 DP 资源分配题的得分，线性规划和指派问题可用排除法处理。

网络流量路径优化 · 结构化知识点清单

知识点名称

网络路径畅通率计算（概率乘法在路径优化中的应用）

核心定义/结论

基本关系

  • 畅通率 = 1 - 拥堵率
  • 全路径畅通率 = 各路段畅通率的连乘积

判断标准：全路径畅通率越高，该路线越优

数学本质：各路段独立事件的联合概率（"且"关系 → 乘法）

典型题型与解题要领

题型：给定带权有向图，各边权值为拥堵率，求最优路径

解题步骤

  1. 将各路段拥堵率转换为畅通率（1 - 拥堵率）
  2. 对每条候选路径，将沿途各段畅通率连乘
  3. 比较各路径结果，取最大值

快速解题技巧：找各选项的公共前缀路段，跳过不计算，直接从分叉点开始比较。重点盯住畅通率特别低的路段（如畅通率 ≤ 0.3），含该路段的选项优先排除。

易错点与注意事项

  • 题目给的是拥堵率，计算前必须先转换为畅通率，不能直接连乘拥堵率
  • 路段数越多不代表越差，关键看各段畅通率的乘积，不能凭路段数量判断优劣
  • 连乘顺序不影响结果，但漏乘某一段会导致答案错误，建议按路径顺序逐段列出
  • 本知识点属于了解级别，考试中不会出现复杂的网络流算法，只考概率连乘

推荐复习顺序

  1. 先理解畅通率与拥堵率的互补关系（1分钟）
  2. 理解为何用乘法（独立事件联合概率）
  3. 练习1-2道例题，熟悉连乘计算流程
  4. 掌握"公共前缀跳过 + 瓶颈路段优先排除"的快速解题法
  5. 不必深入研究最大流、最短路等图论算法，性价比低

建模概念 · 结构化知识点清单

知识点名称

数学建模基本概念（含灵敏性分析、蒙特卡洛方法）

核心定义/结论

数学建模的本质

把现实问题抽象成数学语言，通过求解数学模型来解决实际问题。是一个简化、抽象、迭代的过程。

四个基本特征（必须全部理解）

  • 模型是现实的简化抽象，不是完整复制
  • 简单性与准确性之间需要权衡，不可兼得
  • 评价标准因问题而异，不存在统一普适标准
  • 建模是迭代过程，需要从失败和反馈中持续改进

灵敏性分析

求出最优解后，分析模型结果对参数变化的响应程度。参数变化大但结果变化小 → 模型鲁棒；参数稍变结果剧变 → 该参数是关键变量。

蒙特卡洛方法

基于概率统计的数值计算方法。核心思路：在包含目标区域的规则形状内随机撒点，用命中比例估算目标区域的面积/体积。适合复杂几何体或高维积分的近似计算。

典型题型与解题要领

题型1：判断建模特征描述正误（47题）

解题要领：警惕"统一""普适""唯一""绝对"等绝对化表述，这类说法在软考中大概率是错的。建模的核心是"具体问题具体分析"。

题型2：识别建模后续分析步骤（38题）

解题要领：题干出现"参数变化""检验结果对参数的反应程度"，直接锁定灵敏性分析。四个干扰项各有侧重：一致性管"统不统一"，准确性管"准不准"，似然性管"可不可能"，只有灵敏性管"敏不敏感"。

题型3：选择最适合的近似计算方案（34题）

解题要领：题目强调"最容易理解、最容易编程实现"，这是蒙特卡洛的标志性优势。只要看到"随机点 + 比例估算 + 复杂形状"，直接选蒙特卡洛。

易错点与注意事项

  • C选项"统一普适标准"是经典陷阱，初看觉得"标准化"是好事，但建模评价标准本质上是问题驱动的，不能一刀切
  • 灵敏性分析容易和准确性分析混淆：准确性是"算得准不准"，灵敏性是"参数变了结果抖多少"，两者方向完全不同
  • 蒙特卡洛的关键词是"随机"和"比例"，不是精确计算，是近似估算，题目问"近似计算"时优先考虑它
  • 蒙特卡洛不适合追求精确解的场景，它的优势在于实现简单、适应复杂形状，而非精度最高

推荐复习顺序

  1. 先理解数学建模四个基本特征（47题），建立整体认知框架
  2. 再掌握灵敏性分析的概念和使用场景（38题），区分四种分析类型
  3. 最后学蒙特卡洛方法（34题），理解其适用场景和编程实现逻辑
  4. 做完三题后，回头用"绝对化表述 → 大概率错"这个规律串联复习，加深印象

知识点归纳：指派问题（预测决策）

知识点名称

指派问题 / 匈牙利算法（Assignment Problem）

核心定义/结论

将 N 个人分配到 N 个岗位，每人只做一个岗位，求总成本最小（或最大）的分配方案。

核心结论：

  • 属于 0-1 整数规划的特殊形式
  • 匈牙利算法通过"行归约 → 列归约 → 找独立零"三步求解
  • 最优解对应归约矩阵中"不同行不同列的独立零"位置
  • 回原始矩阵取对应值求和，即为最优总成本

典型题型与解题要领

题型：给出 N×N 工时/成本矩阵，求最优分配方案及最小总值。

解题要领：

方法一：穷举法（考场首选）

  • 先找每行最小值，尝试组合不冲突的分配
  • 对照选项验证，4个选项差距小，试2~3组即可命中

方法二：匈牙利算法（理解步骤即可）

```

第一步 行归约：每行减去本行最小值

第二步 列归约：每列减去本列最小值

第三步 找独立零：在不同行不同列中各选一个0

第四步 回原表：按分配方案查原始工时，求总和

```

本题示例：

```

原始矩阵 行归约后 列归约后（D列-1）

甲 7 5 2 3 → 5 3 0 1 → 5 3 0 0

乙 9 4 3 7 → 6 1 0 4 → 6 1 0 3

丙 5 4 7 5 → 1 0 3 1 → 1 0 3 0

丁 4 6 5 6 → 0 2 1 2 → 0 2 1 1

独立零：甲→D, 乙→C, 丙→B, 丁→A

原表取值：3 + 3 + 4 + 4 = 14

```

易错点与注意事项

  • 找独立零时容易"撞车"（同行或同列选了两个零），需逐步排除
  • 列归约只对最小值不为0的列操作，最小值已是0的列不用动
  • 最终求和必须回原始矩阵取值，不是归约后矩阵的值
  • 最大化问题需先将矩阵取负或用最大值减各元素，转化为最小化再求解

推荐复习顺序

  1. 理解问题本质：N人N岗一对一分配，求最优总成本
  2. 掌握穷举法：考场实用，快速验证选项
  3. 了解匈牙利算法三步流程：行归约 → 列归约 → 找独立零
  4. 做1~2道真题练手，重点练"找独立零"和"回原表取值"
  5. 了解最大化变形（取负转最小化），作为扩展了解

线性规划 · 结构化知识点清单

知识点名称

线性规划（二维平面最优解求解）

核心定义/结论

线性规划是在一组线性约束条件下，求目标函数（线性表达式）最大值或最小值的方法。

三条核心结论：

  1. 可行域是凸多边形（凸集），由各约束条件的边界线围成
  2. 目标函数的最优值一定在可行域的顶点处取得
  3. 若 X 和 Y 都是最优解，则满足 λ≥0、μ≥0、λ+μ=1 的凸组合 λX+μY 也是最优解

典型题型与解题要领

题型一：求目标函数的最大值/最小值（题43、题45）

解题套路固定，五步走：

```

① 将所有不等式取等号，画出边界直线

② 判断每个不等式对应哪侧区域，确定可行域

③ 求可行域所有顶点坐标（联立边界线方程）

④ 将每个顶点代入目标函数，计算结果

⑤ 比较大小，取最大或最小

```

求极小值时，从下往上平移目标函数直线，第一个碰到可行域的点就是极小值点。

题型二：最优解的性质判断（题9）

直接记结论：凸组合条件 = 非负（λ,μ≥0）+ 和为1（λ+μ=1），两个条件缺一不可。

易错点与注意事项

顶点验证不能省

联立两条边界线求出的交点，必须代回所有约束条件验证是否合法。不满足的点直接排除，不能代入目标函数。

题43中 (5,0) 看起来像顶点，但代入 x+2y≥10 得 5<10，不满足，直接排除。

凸组合的两个条件都要有

  • 只有 λ+μ=1，没有非负限制 → λ 可能为负，点跑到线段延长线外
  • 只有 λ,μ≥0，没有和为1 → 点可能跑到线段外部
  • λ+μ=2 → 明确超出线段范围

可行域可能是无界的

当约束条件只有下界没有上界时，极大值可能不存在，但极小值仍在顶点处。

推荐复习顺序

  1. 先掌握"找顶点代入"这一核心操作（题45，约束简单，顶点好找）
  2. 再练习含多个约束的顶点筛选与验证（题43，有无效顶点需排除）
  3. 最后记忆凸组合性质结论（题9，纯概念，背住即可）

> 软考考查深度有限，掌握"找顶点→验证→代入比大小"这一套路，加上凸组合的结论，覆盖全部出题方向。

官方解析

本题考察的是三机流水车间（Flow Shop）调度的Johnson法（扩展到三工序），目标是最小化总完工时间（Makespan）。

已知三道工序顺序固定：设计(M1)→制造(M2)→检验(M3)。各作业时间：

甲：(13,15,20)；乙：(10,20,18)；丙：(20,16,10)；丁：(8,10,15)。

当问题为三机同序流水线时，可引入两台“虚拟机器”：G=M1+M2，H=M2+M3，并对(G,H)应用Johnson法排列作业顺序。计算：

丁：G=8+10=18，H=10+15=25

甲：G=13+15=28，H=15+20=35

乙：G=10+20=30，H=20+18=38

丙：G=20+16=36，H=16+10=26

最小为丁的G=18，排在最前；从余下中最小为丙的H=26，排在最后；

在剩余甲、乙中，最小为甲的G=28，排在当前最前；最后为乙。

由此得到最优序列：丁→甲→乙→丙。

在该序列下，逐机计算完工时间（单位：天）：

丁：M1 0–8；M2 8–18；M3 18–33

甲：M1 8–21；M2 max(18,21)=21–36；M3 max(33,36)=36–56

乙：M1 21–31；M2 max(36,31)=36–56；M3 max(56,56)=56–74

丙：M1 31–51；M2 max(56,51)=56–72；M3 max(74,72)=74–84

官方解析

本题考察的是几何概型。

设1路、2路公交车分别到达的时间为随机变量 x 和 y，且 x,y ~ U(0,10)，相互独立。问题转化为求：

P(|x-y| ≤ 4)。

在坐标系中考虑 (x,y)，其点均匀分布在 [0,10]×[0,10] 的正方形区域内，总面积为 100。

条件 |x-y| ≤ 4 对应于正方形中位于直线 y=x±4 之间的带状区域。

超出部分为两个直角等腰三角形（边长均为 6），每个面积 = 6×6/2 = 18。两个合计面积 = 36。

因此符合条件的区域面积 = 100 - 36 = 64。

所求概率 = 64 / 100 = 0.64。

所以正确答案是 C. 0.64。

在“只能做上衣或裤子”的前提下，应当让“做上衣相对更有优势的组做上衣、做裤子相对更有优势的组做裤子”，再用等量约束平衡上衣与裤子数量。

裤子总数为P=甲6×15+乙7(15−x)+丙8(15−y)=90+[105−7x]+[120−8y]=315−7x−8y。

> 不是真实收益，是"按概率打折后的平均结果"

顾名思义记忆：

  • 期望 → 你"期望"能拿到的钱（不一定真拿到）
  • 概率 → 事情发生的可能性，用小数表示（70% = 0.7）
  • 期望收益 = 每种结果的收益 × 它发生的概率，全部加起来

```

期望收益 = 结果A的收益 × 概率A + 结果B的收益 × 概率B

```

拥堵率这条路堵车的概率，0=完全不堵，1=完全堵死"堵"的概率，越大越堵

为什么要"连乘"？

> 想象你开车经过3个路口，每个路口都要"碰运气"不堵车

>

> 第1关顺利 且 第2关顺利 且 第3关顺利 → 全程才顺利

>

> "且"在概率里就是乘法

```

全程畅通率 = 第1段畅通率 × 第2段畅通率 × 第3段畅通率 × ...

```

本题考察的是资源分配类动态规划（投资组合优化） 的建模与求解。

解题思路：先用甲厂初始化，再依次并入乙、丙两厂。由题表可读出甲在0～4时效益分别为3.8、4.1、4.8、6.0、6.6；乙在0～4时分别为4.0、4.2、5.0、…（据表取值）；丙在0～4时分别为4.8、6.4、6.8、7.8、7.8。

应用数学 难度：0

某厂生产的某种电视机，销售价为每台 2500 元，去年的总销售量为 25000 台，固定成本总额为 250 万元，可变成本总额为 4000 万元，税率为 16%，则该产品年销售量的盈亏平衡点为（）台（只有在年销售量超过它时才能盈利）。

子题1

参考答案：A

官方解析

本题考察盈亏平衡点的概念和计算方法。

本题难点在于可变成本的处理方式，由于销售收入为：$25000 \times 2500 = 6250\,万\text{元}$

可变成本为 4000 万元，因此可变成本占比为：$\frac{4000}{6250} = 64\%$

设盈亏平衡时的销售量为 X 台，列方程如下：

$2500000 + X \times 2500 \times 64\% + X \times 2500 \times 16\% = X \times 2500$

$2500000 + X \times 2500 \times (0.64 + 0.16) = X \times 2500$

$1000 + 0.8X = X\Rightarrow X = 5000$

该产品的年销售盈亏平衡点为 5000 台，只有在销售量超过该值时，企业才会盈利。

第15题（题号：58）

概率统计 难度：1

计算机产生的随机数大体上能在（0，1）区间内均匀分布。假设某初等函数 f(x) 在（0，1）区间内取值也在（0，1）区间内，如果由计算机产生的大量的（M个）随机数对（r1，r2）中，符合 r2 ≤ f(r1) 条件的有N个，则 N/M 可作为（）的近似计算结果。

子题1

参考答案：D

官方解析

本题可根据几何概型的原理，结合定积分的几何意义来分析$\frac{N}{M}$所代表的近似计算结果。

1.分析随机数对$(r1, r2)$的分布情况

已知计算机产生的随机数对$(r1, r2)$在$(0, 1)\times(0, 1)$这个正方形区域内均匀分布（其中$(0, 1)\times(0, 1)$表示横坐标$r1$取值范围是$(0, 1)$，纵坐标$r2$取值范围也是$(0, 1)$ ，该正方形区域的面积$S = 1\times1 = 1$ 。

2.分析满足$r2\leq f(r1)$的区域

对于每一个$r1$，满足$r2\leq f(r1)$的点$(r1, r2)$构成的区域，从几何角度看，在$x - y$平面（这里$x$对应$r1$，$y$对应$r2$ 上，它是由曲线$y = f(x)$（$x\in(0, 1)$ ）与$x = 0$，$x = 1$，$y = 0$所围成的区域。

根据定积分的几何意义，对于函数$y = f(x)$，在区间$[a, b]$上，定积分$\int_{a}^{b}f(x)dx$表示由曲线$y = f(x)$、直线$x = a$、直线$x = b$以及$x$轴所围成的曲边梯形的面积。

在本题中，$a = 0$，$b = 1$，那么$\int_{0}^{1}f(x)dx$就表示由曲线$y = f(x)$（$x\in(0, 1)$ ）与$x = 0$，$x = 1$，$y = 0$所围成区域的面积。

3.根据几何概型计算概率

根据几何概型的概率计算公式$P(A)=\frac{构成事件A的区域长度(面积或体积)}{试验的全部结果所构成的区域长度(面积或体积)}$

在本题中，事件$A$为随机数对$(r1, r2)$满足$r2\leq f(r1)$，试验的全部结果所构成的区域是$(0, 1)\times(0, 1)$正方形区域，面积为$1$；构成事件$A$的区域面积就是$\int_{0}^{1}f(x)dx$ 。

当产生大量随机数对$(M 个)$时，满足$r2\leq f(r1)$的随机数对有$N$个，根据频率趋近于概率，$\frac{N}{M}$近似等于事件$A$发生的概率，也就是$\int_{0}^{1}f(x)dx$ 。

第16题（题号：9）

线性规划 难度：1

如果X和Y都是某线性规划问题的最优解，则当（）时，λX+μY一定也是其最优解。

子题1

参考答案：B

官方解析

本题考察的是线性规划最优解的凸性性质。

在线性规划中，目标函数是线性的，约束条件构成一个凸多面体（即可行域是一个凸集合）。一个重要的性质是：如果X和Y都是最优解，则在X和Y之间的任意凸组合也是最优解。

所谓凸组合，指的是形如 λX + μY，且满足 λ ≥ 0，μ ≥ 0，λ + μ = 1 的线性组合。它代表从X到Y之间连线上所有点，属于线段内的点。

A选项 λ+μ=1：缺少λ,μ≥0的限制，不一定保证是凸组合，不正确。

B选项 λ,μ≥0，λ+μ=1：符合凸组合的定义，表示X与Y之间所有的线性插值点，这些点也都是最优解，正确。

C选项 λ,μ≥0：这只是线性组合的非负条件，但λ+μ不一定为1，可能会超出X与Y之间的连线段，不一定仍是最优解，不正确。

D选项 λ,μ≥0，λ+μ=2：不满足凸组合的定义，实际表示在X与Y之间连线的外部延长线上，不能保证仍是最优解，不正确。

因此，选项 B 正确。

第二步：顾名思义记忆法 🧠

🌟 "凸组合" = 两点之间走直线，不能出界

> 想象你站在 X 点，朋友站在 Y 点，你们之间拉了一根绳子。

> 凸组合就是这根绳子上的任意一个位置。

> - 必须在绳子上（λ+μ=1，比例加起来是100%）

> - 不能跑到绳子外面（λ≥0，μ≥0，两个比例都不能是负数）

第三步：答案核心记忆口诀 🗣️

```

两个非负加等一，

线段之内是最优。

比例为负跑出界，

和不等一也不对。

```

解释：

  • "两个非负" → λ≥0，μ≥0（两个系数都不能是负数）
  • "加等一" → λ+μ=1（加起来等于1，也就是100%）
  • "线段之内是最优" → 满足这两个条件，就是在X和Y连线段内，也是最优解

```

| 这段是最优解 |

→ λ可能是负数，比如λ=-1,μ=2

→ 跑到Y点右边延长线上去了 ❌

B: λ,μ≥0 且 λ+μ=1 ✅

→ 老老实实在X和Y之间的线段上

C: λ,μ≥0 但没说加等于1

→ λ=1,μ=1 时，λ+μ=2，跑到线段外面了 ❌

```

第17题（题号：3）

应用数学 难度：0

0-1000的数字里，只有一个5的数字个数（）。

子题1

参考答案：B

官方解析

本题考察的是组合计数与排除法的综合运用。

第一种情况，1位数。在 0 到 9 之间，只有数字 5 是符合条件的。所以只有 1 个数字。

第二种情况，2位数。对于 10 到 99 之间的两位数，5 只能出现在十位或个位。

十位是 5 时，个位可以是任意的 0 到 9（除了 5），共有 9 个数字（50, 51, 52, 53, 54, 56, 57, 58, 59）。

个位是 5 时，十位可以是任意的 1 到 9（除了 5），共有 8 个数字（15, 25, 35, 45, 65, 75, 85, 95）。

所以，共有 9 + 8 = 17 个符合条件的两位数。

第三种情况，3位数。对于 100 到 999 之间的三位数，5 只能出现在百位、十位或个位。

百位是 5 时，十位和个位可以是任意的 0 到 9（除了 5），共有 9 × 9 = 81 个数字。

十位是 5 时，百位不能是0和5，所以只有8种选择，个位不能是5，有9种选择，所以共有 8 × 9 = 72 个数字。

个位是 5 时，百位不能是0和5，所以只有8种选择，十位不能是5，有9种选择，所以共有 8 × 9 = 72 个数字。

所以，共有 81 + 72 + 72 = 225 个符合条件的三位数。

因此，0 到 1000 之间，包含且仅包含一个 5 的数字个数为：1+17+225=243
